## 11. 已知限制（非缺陷）

- Android 端暂缓（按 BR8）
- 穿透态下桌宠不可见、只保留小眼睛按钮（设计如此，详见面板提示）
- 发丝缝隙的灰块是 rembg 抠图残留，需 PS 精修（见 `docs/ASSET_GUIDE.md` §三）
- 最大尺寸由工作区高度决定；超出屏幕物理上无法完整显示，故滑杆上限是动态的
